# Архитектурные решения

## ADR-001. Raw SQL и общая PostgreSQL

### Контекст
Repositories обращаются к `public.*` и `wms.*`.
### Решение
`asyncpg`, raw SQL и DB-side state.
### Причины
Причина не установлена по коду, требуется подтверждение команды.
### Последствия
Сильная связанность и скрытая DB-логика.
### Статус
Фактически используется.

## ADR-002. Синхронная 1С после commit

### Контекст
Returns, receipts, kits, resorting и FBO уведомляют 1С.
### Решение
Прямой `ONECRouting` из service.
### Причины
Не установлены.
### Последствия
Partial success, no retry.
### Статус
Фактически используется.

## ADR-003. RabbitMQ для стикеров

### Контекст
Генерация асинхронна.
### Решение
Durable direct exchanges/queues, task DB, S3 и Redis.
### Причины
Не документированы.
### Последствия
Async task lifecycle; DLQ/retry не видны.
### Статус
Принято.

## ADR-004. WMS error не отменяет receipt

### Контекст
`ReceiptOfGoodsService` ловит exception.
### Решение
Вернуть DB success с warning.
### Причины
Комментарий указывает сохранение основной/обратно совместимой логики.
### Последствия
Допускается рассогласование.
### Статус
Фактически используется.

## ADR-005. Versioning через `is_valid`

### Контекст
1С повторно выгружает documents.
### Решение
Invalidate old rows, insert current.
### Причины
Не установлены.
### Последствия
История сохраняется, но concurrency guard не подтверждён.
### Статус
Фактически используется.
